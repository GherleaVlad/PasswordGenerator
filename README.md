# Password Generator

### About
A simple password generator built for practice and maybe personal use!

### Features
- Built with Python using `random` and `tkinter`.
- Two password generation modes: **Simple** and **Complex**.
- **Simple:** Uses custom user input and allows additional character options.
- **Complex:** Automatically generates a password with a customizable length.
- Passwords can contain lowercase and uppercase letters, numbers, and symbols.
- Users can save generated passwords and their purpose in a `.txt` file.
- Users can choose where to save the file.
- No database required.

# Generator de parole

### Despre proiect
Un generator simplu de parole, creat pentru exercitiu si, eventual, uz personal!

### Functionalitati
- Dezvoltat in Python, folosind `random` si `tkinter`.
- Doua moduri de generare: **Simpla** si **Complexa**.
- **Simpla:** Porneste de la textul introdus de utilizator, cu posibilitatea de a adauga alte tipuri de caractere.
- **Complexa:** Genereaza automat o parola cu lungime configurabila.
- Parolele pot contine litere mici, mari, cifre si simboluri.
- Parolele si scopul lor pot fi salvate intr-un fisier `.txt`.
- Utilizatorul poate alege locatia de salvare.
- Nu necesita baza de date.
